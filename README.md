# 🧠 HSE-FLS — Human Stress–Environment Feedback Loop System

## 🌐 Live Preview

**[Open HSE-FLS](https://hse-fls.web.app/)**

## 🧭 Overview

**HSE-FLS (Human Stress–Environment Feedback Loop System)** is an IoT prototype designed to monitor physiological indicators associated with stress and provide real-time environmental feedback.

The system combines an **ESP32**, physiological sensors, data processing and automated environmental control into a closed feedback loop.

## 🔄 Feedback Loop

```text
Physiological Sensors
        ↓
      ESP32
        ↓
Data Collection & Processing
        ↓
 Stress Detection
        ↓
Environmental Response
        ↓
 Continuous Monitoring
        ↺
```

## 🚀 Key Features

- Real-time physiological signal monitoring
